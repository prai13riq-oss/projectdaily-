# DailyMe — คู่มือโปรเจกต์

DailyMe เป็นเว็บไซต์ช่วยวางแผนชีวิตประจำวัน ทำด้วย HTML, CSS และ JavaScript

## วิธีเปิด
1. แตกไฟล์ ZIP (Extract All)
2. เปิดโฟลเดอร์ `DailyMe` ใน VS Code
3. เปิด `index.html` ในเบราว์เซอร์เพื่อทดลองหน้าเว็บ
4. ถ้าต้องการให้ทุกหน้าทำงานผ่านเว็บเซิร์ฟเวอร์ สามารถใช้ส่วนขยาย Live Server หรือวิธีที่ครูแนะนำได้

## ไฟล์หลัก
- `index.html` — หน้าแรก
- `outfit.html` — หน้าเลือกชุด
- `weather.html` — หน้าข้อมูลอากาศ
- `bag.html` — หน้าจัดกระเป๋าและ checklist
- `mood.html` — หน้าเพลงและคำแนะนำตามอารมณ์
- `style.css` — รูปแบบและสีของเว็บไซต์
- `js/main.js` — ปุ่มเปลี่ยนหน้า
- `js/outfit.js` — การเลือกชุด
- `js/weather.js` — การแสดงข้อมูลอากาศ
- `js/bag.js` — การเลือกของใส่กระเป๋าและ checklist
- `js/mood.js` — เพลงและการทำงานของหน้า Mood
- `images/` — รูปภาพประกอบ
- `music/` — ไฟล์เพลง

## ถ้าต้องการแก้เว็บ
- แก้ข้อความและโครงสร้างในไฟล์ `.html`
- แก้สี ขนาด ระยะห่าง และหน้าตาใน `style.css`
- แก้ปุ่มและการทำงานในไฟล์ `.js` ที่ตรงกับหน้านั้น

**หมายเหตุ:** ไฟล์ JavaScript บางส่วนอาจมีโค้ดหลายบรรทัดเพราะต้องควบคุมการทำงานของฟีเจอร์เดิม อย่าลบโค้ดที่ไม่เข้าใจทันที ให้ทดลองทีละส่วนและบันทึกสำเนาก่อนแก้
